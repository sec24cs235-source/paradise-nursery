# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery - Online Plant Shop

## Project Description
Paradise Nursery is a React and Redux based shopping application for an online plant nursery. Users can browse plants by category, add plants to a shopping cart, update quantities, remove products, and view the total cart amount.

## Technologies Used
- React
- Vite
- Redux Toolkit
- React Redux
- JavaScript
- CSS

## Main Features
- Paradise Nursery landing page
- About Us section
- Three plant categories
- 18 unique plants
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease quantity
- Delete cart items
- Total cost calculation
- Continue Shopping
- Checkout Coming Soon message
